# 服务发现与证据管理

CSUST CLI 的服务目录来自对学校服务的有限探索和适配结果。它的作用是帮助调用者知道“现在能尝试什么、证据有多强”，不是生成一份永远正确的学校 API 清单。

## 探索目标

探索以业务价值为主线：

| 优先级 | 判断标准 | 处理方式 |
| --- | --- | --- |
| `CORE` | 教务、认证和学生高频事务 | 深入验证读写流程和成功证据 |
| `ENABLER` | VPN、SSO、权限和网关等基础能力 | 优先保证会话和依赖关系清楚 |
| `UNIQUE` | 学校特有的档案、实验、评价和事务 | 抽象业务模型，保留特有能力 |
| `COMMODITY` | 通用产品已经能较好替代 | 只做有明确使用价值的部分 |
| `CONTENT` | 纯展示或静态内容 | 维持必要的只读入口 |
| `UNKNOWN` | 证据不足以分类 | 有限继续探索，或记录无法验证 |

页面多、URL 多或技术上容易解析，不等于业务价值高。没有可验证的业务行为时，目录只记录入口状态。

## 证据来源

一个能力的证据可能来自：

- 官方入口、公开说明和服务链接；
- 真实响应中的结构化 JSON、明确状态或登录探针；
- 前端资源暴露的请求约定；
- 旧式 HTML 表单及其字段/状态变化；
- 连接失败、默认页、403/5xx 或其他反向证据。

证据要说明“看到了什么”和“因此能承诺什么”。例如，看到登录页只能证明入口存在，不能证明已取得业务接口；看到一个成功的查询响应，也不能自动推导出写接口存在。

## 置信度的含义

目录中的 `confidence` 是维护和调用决策信号：

- `high`：已有可重复的结构化协议、明确登录确认或业务响应。
- `medium`：已有公开页面、部分协议或前端线索，但仍需调用时验证。
- `low`：当前不可达、默认页、拒绝访问或只有推测，不能承诺业务能力。

每个低置信度条目都应有具体的 `confidence_evidence`。证据应避免秘密、个人信息和无法复核的主观描述，并在服务状态可能快速变化时带上探测日期。

## 推荐的发现流程

1. 写清楚业务目标、用户角色、读写边界和期望的成功证据。
2. 从官方入口、服务大厅或已有目录找到候选服务。
3. 在开发阶段使用 Playwright CLI 观察页面、网络请求、响应和状态变化。浏览器探索不进入 Go 运行时。
4. 优先确认公开/结构化协议，再确认认证、分页、文件和写操作；不要从页面按钮数量推断能力覆盖。
5. 记录服务主机、认证前置、对象标识、成功/拒绝/未知结果和不可用原因。
6. 设计语义参数和统一结果字段，把隐藏字段、内部路径和协议细节留在 adapter。
7. 用本地模拟服务验证映射和状态转换，再决定是否提升目录置信度。
8. 更新目录证据，并在文档或提交说明中区分“已实现”“已探测”“当前未验证”。

## 目录不是静态 API 文档

目录中的 `name`、`service` 和命令入口不一定是一一对应关系。一个上游系统可以承载多个业务条目，一个业务命令也可能根据参数选择不同的服务。调用者应先读目录中的描述，再用命令帮助确认实际入口。

目录中的 `host`、`url` 和内部路径主要用于识别证据，不应复制到智能体提示词、脚本参数或对外文档中作为稳定接口。服务地址、重定向和网关前缀都属于 adapter 的维护范围。

## 发现结果的生命周期

```text
候选入口
  → 有页面/协议证据
  → 适配器可复现
  → 业务结果可验证
  → 目录记录能力
  → 上游变化后重新探测
```

如果上游返回默认页、拒绝访问、网关错误或结构变化：

1. 先降低能力承诺，不删除历史上下文或伪造空结果。
2. 判断是网络/权限、认证、入口变化还是字段解析变化。
3. 只在对应 adapter 内修复协议变化；公共 transport 只有在跨服务证据充分时才修改。
4. 若暂时无法复现，保留低置信度状态和原因，等待下一次有效探测。

## 写操作的发现原则

写接口必须比读接口多一层证据：不仅要知道请求如何发送，还要知道服务如何表示拒绝、成功和重复提交。适配前先确认：

- 目标对象如何唯一识别；
- 当前账号是否具备资格；
- 服务是否有时间窗口或并发版本；
- 成功是否能通过响应、列表回读、详情回读或状态变化确认；
- 请求超时或响应损坏时如何避免盲目重试。

不能证明这些条件时，保留查询或状态能力，不把猜测实现成写命令。

## 不应做的探索

- 不把学校服务当作任意 URL 的通用代理。
- 不把浏览器 DOM 结构变成公共 CLI 参数。
- 不把一次偶然的 HTTP 200、空列表或前端按钮当作业务成功证据。
- 不在真实账号上反复试探高影响写操作。
- 不把未验证的内部地址、令牌格式或页面隐藏字段写进稳定文档。
